Custom WordPress theme for Spark VN, built from the Underscores (_s) starter.

== Description ==

Spark VN is a classic/hybrid starter theme. It keeps the Underscores template hierarchy (header.php, index.php, template-parts, inc/) and adds theme.json so the block editor shares the same colors, typography, and content width.

Do not use this as a parent theme. Customize it directly.

== Installation ==

1. Keep the theme in `wp-content/themes/sparkvn`.
2. In wp-admin go to Appearance > Themes and activate Spark VN.
3. Assign a menu to the Primary location (Appearance > Menus).
4. Optional: assign a Footer menu and add widgets to Sidebar / Footer.

== Frequently Asked Questions ==

= Does this theme support WooCommerce? =

Yes. Compatibility files from Underscores load automatically when WooCommerce is active.

= How do I compile Sass? =

From the theme directory: `npm install` then `npm run compile:css` or `npm run watch`.
